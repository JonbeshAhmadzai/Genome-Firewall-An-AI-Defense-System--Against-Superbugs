# Demo input

`mock_genome.fna` is a small synthetic FASTA made for local UI demonstrations.
It is useful for checking upload, FASTA QC, AMRFinderPlus execution, and JSON
response rendering. It is not a real isolate and must not be used for clinical,
benchmarking, or biological conclusions.

Upload it in the HTML dashboard at `http://127.0.0.1:8001/`.
